Cài đặt Shadowrocket (v2.2.92) 🛡️ Cài Cấu Hình DNS Chống Thu Hồi Chứng Chỉ Install Anti-Revoke DNS Profile
💡 Lưu ý khi cài đặt:
1. Khuyên dùng Server 1 — Bản Chính Hãng Apple để cài đặt trực tiếp không cần DNS.
2. Với các Server ghi "Enterprise • Cần DNS", hãy cài 🛡️ Cấu Hình DNS Chống Thu Hồi và vào Cài đặt → Cài đặt chung → Quản lý VPN & Thiết bị để Tin cậy chứng chỉ.
💡 Installation Notes:
1. Recommended: Use Server 1 — Official Apple for instant installation without DNS.
2. For "Enterprise • Cần DNS" servers, install the 🛡️ Anti-Revoke DNS Profile and trust the Enterprise Certificate in Settings → General → VPN & Device Management.
⚠ Chỉ mở bằng Safari trên iPhone/iPad. Không dùng Chrome hoặc Android. Open in Safari on iPhone/iPad only.
