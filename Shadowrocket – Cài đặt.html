Cài đặt Shadowrocket (v2.2.92) 🛡️ Cài Cấu Hình DNS Chống Thu Hồi Chứng Chỉ Install Anti-Revoke DNS Profile
💡 Lưu ý khi cài đặt:
1. Với các Server ghi "Cần DNS", hãy bấm nút 🛡️ Cài Cấu Hình DNS Chống Thu Hồi và kích hoạt trong Cài đặt trước khi tải.
2. Sau khi tải xong, vào Cài đặt → Cài đặt chung → Quản lý VPN & Thiết bị → Bấm Tin cậy chứng chỉ doanh nghiệp.
3. Nếu 1 Server báo không tải được trên máy bạn, hãy chạm chọn Server kế tiếp.
💡 Installation Notes:
1. For "Enterprise • Cần DNS" servers, install & enable the 🛡️ Anti-Revoke DNS Profile first.
2. Go to Settings → General → VPN & Device Management → Trust the Enterprise Certificate.
3. If one server fails on your device, switch to the next server above.
⚠ Chỉ mở bằng Safari trên iPhone/iPad. Không dùng Chrome hoặc Android. Open in Safari on iPhone/iPad only.
